## 🆘 TROUBLESHOOTING QUICK ANSWERS

**Q: My development server won't start**
A: 
```powershell
# Check if port is in use
netstat -ano | findstr :3000
# Kill the process: taskkill /PID <PID> /F
# Try again: npm run dev
```

**Q: Screenshots are too small to read**
A: Zoom browser to 125% before taking screenshot (Ctrl + +)

**Q: PDF is too large**
A: Compress images using TinyPNG.com

**Q: I can't access the backend API**
A: Verify backend is running on port 3001

**Q: Where do I add screenshots in markdown?**
A:
```markdown
![Screenshot Name](./screenshots/Chapter3/filename.png)
```

**Q: How do I convert markdown to PDF?**
A: Use Pandoc: `pandoc file.md -o file.pdf`

**Q: What if I'm missing a test result?**
A: See SUBMISSION_CHECKLIST.md Chapter 4 section

**Q: Should I include all code?**
